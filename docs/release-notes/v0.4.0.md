# v0.4.0 — Silent Auto-Update / 静默自动更新

## English

- **Silent auto-update** for the NSIS installer, powered by electron-updater:
  - Checks GitHub Releases on startup (15 s after launch) and every 6 hours.
  - New versions download automatically in the background; they install when you quit the app.
  - Toggle in **Settings → 宿主更新**: automatic download can be disabled; manual check / download / restart-to-install are available.
  - A header chip shows update progress (`⟳ vX.Y.Z 42%`, `新版本已就绪，重启安装`).
- **Portable edition**: portable executables cannot update themselves in place — the app now detects this and links to the latest release page instead of pretending to update.
- Release channel is baked in (`pokong918/all-tools`); fork users can point updates at their own repo via the existing "发布仓库" setting.
- Packaging now generates `latest.yml` (electron-updater metadata) and it ships as a release asset.
- Release process scripted: `host/scripts/release.mjs` (idempotent create + asset upload incl. `latest.yml`).

Upgrade notes: install this version once via `All-Tools-Setup-0.4.0.exe`; later versions will offer in-app updates automatically.

## 简体中文

- NSIS 安装版接入 **electron-updater 静默自动更新**：
  - 启动后 15 秒、之后每 6 小时检查一次 GitHub Releases；
  - 发现新版本自动后台下载，退出应用时自动安装；
  - 「设置 → 宿主更新」可关闭自动下载，也可手动检查 / 下载 / 重启安装；
  - 顶栏出现更新进度提示（`⟳ vX.Y.Z 42%`、`新版本已就绪，重启安装`），点击直达设置。
- **便携版**：便携 exe 无固定安装目录、无法就地自更新，现已识别该场景并改为引导到最新发布页。
- 更新渠道内置于安装包（`pokong918/all-tools`）；fork 用户可通过既有「发布仓库」设置指向自己的仓库。
- 打包新增生成 `latest.yml`（electron-updater 元数据）并随 Release 上传。
- 发版流程脚本化：`host/scripts/release.mjs`（幂等创建 + 资产上传，含 `latest.yml`）。

升级说明：本版本需手动安装一次 `All-Tools-Setup-0.4.0.exe`，之后的版本将在应用内自动提示更新。
